# ForSTUDENT — расписание ИУБиП

Нативное Android-приложение для группы `К3Ю3(9),К3Ю4(9)`. Kotlin, Jetpack Compose, Room, Glance, WorkManager и AlarmManager. Сервер, регистрация и аккаунт не требуются.

## Функции

- Экраны «Сегодня», «Неделя», «Будильник», «Настройки» на русском языке.
- Виджет показывает опубликованные пары на сегодня, ближайшую пару и компактный вариант.
- Автоматические звонки на опубликованные учебные даты по первой активной паре дня. По умолчанию за 120 минут, часовой пояс `Europe/Moscow`.
- Различаются опубликованный день без пар и ещё не опубликованный день. При неудачной загрузке локальное расписание и запланированные звонки остаются.
- Звуковой экран звонка с выключением и отсрочкой на 10 минут.

## Архитектура

`source/` содержит единственный адаптер к недокументированному сайту (`IubipScheduleClient`, `IubipScheduleParser`). `domain/` — модель урока, таблица времени и чистое планирование. `data/` — Room и настройки. `sync/` — периодическая загрузка. `alarm/` — точные звонки и системные события. `widget/` — Glance. Экранное приложение находится в `MainActivity.kt`.

Источник и зафиксированная схема описаны в [docs/source-observation.md](docs/source-observation.md). Тестовые JSON обезличены; они не являются действующим расписанием.

Результаты сборки, тестов и запуска на эмуляторе — в [docs/verification.md](docs/verification.md).

## Сборка

Нужны JDK 17, Android SDK Platform 37.0 и Build Tools 37.0.0. Android 17 SDK устанавливается как preview-пакет `platforms;android-37.0`.

```bash
./gradlew testDebugUnitTest assembleDebug
```

На Windows: `gradlew.bat testDebugUnitTest assembleDebug`. Собранный debug APK включён в репозиторий: [dist/ForSTUDENT-debug.apk](dist/ForSTUDENT-debug.apk). Новая сборка появится в `app/build/outputs/apk/debug/app-debug.apk`. Instrumentation-проверка Room: `./gradlew connectedDebugAndroidTest` с запущенным эмулятором или подключённым телефоном.

## Установка и разрешения

Установите APK на Android 8.0 или новее, откройте приложение и нажмите «Обновить». Для автоматических звонков включите переключатель на вкладке «Будильник» и разрешите **Точные будильники**. На Android 13+ разрешите **Уведомления**; на Android 14+ проверьте доступ к полноэкранному экрану звонка. Если точные звонки недоступны, вкладка показывает предупреждение и кнопку открытия системных часов для ручной настройки.

## Проверка на телефоне

1. Добавьте виджет «Расписание ИУБиП» на домашний экран, сравните день и ближайшую пару с приложением. Уменьшите высоту виджета: должен появиться компактный вариант. Проверьте день без пар и смену даты после полуночи.
2. Разрешите точные будильники, уведомления и полноэкранный экран. На вкладке «Будильник» включите автоматику и установите интервал так, чтобы следующая учебная дата получила будущий звонок. Проверьте системную страницу «Будильники и напоминания» и время следующего звонка в приложении.
3. Для краткой проверки звонка измените интервал перед ближайшей первой парой так, чтобы звонок был через несколько минут. Заблокируйте телефон и дождитесь звука/экрана. Проверьте «Отложить на 10 минут» и «Выключить».
4. Перезагрузите телефон: будущие звонки должны быть восстановлены. Повторно нажмите «Обновить»: дублей быть не должно. При отключённой сети старое расписание и уже назначенные звонки сохраняются.

## Ограничения

- Сайт использует недокументированный POST-интерфейс. При изменении его схемы приложение покажет ошибку данных и сохранит последнюю исправную загрузку.
- Звонки создаются только для опубликованных дат. Если будущая неделя не опубликована, приложение не может заранее назначить звонок на неё.
- WorkManager выполняет фоновую синхронизацию приблизительно раз в шесть часов, а не в строго заданную минуту. Уже опубликованные дни планируются заранее.
- После принудительной остановки приложения Android блокирует его фоновые события до следующего запуска пользователем. Настройки производителя и режим экономии батареи также могут влиять на доставку звука и полноэкранного уведомления.
