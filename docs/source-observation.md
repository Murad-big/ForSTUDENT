# Проверка источника, 24.09.2026

Проверена страница `https://iubip.ru/schedule/?group=К3Ю3(9),К3Ю4(9)` и её сетевой endpoint. При первом GET сайт выдавал HTML-скрипт, который устанавливал cookie `beget=begetok`; без этой cookie POST вернул HTTP 405. С cookie и заголовком Referer запрос `application/x-www-form-urlencoded; charset=UTF-8` с полями `do=schedule` и `group=К3Ю3(9),К3Ю4(9)` вернул HTTP 200 и JSON (28230 символов). Клиент повторяет минимальные необходимые заголовки и cookie. Этот интерфейс сайта не документирован и может измениться.

Верхний ключ JSON совпадал с группой. Его значение было массивом из строки выбранной недели и объекта недель. Наблюдались ключи `5` и `6`; у каждой недели массив из метаданных (`per`, `days`, иногда `today`) и карты дней. Диапазоны: 21.09.2026–27.09.2026 и 28.09.2026–04.10.2026. День содержит ключи номеров пар; значение каждого слота — массив записей. Поля записи включали `DATE`, `LES`, `SUBJECT`, `SUBJ_TYPE`, `NAME`, `AUD`, `SUBG`, `ID`, `deleted`. `DATE` не всегда дополнена нулём: наблюдались значения `24-09-2026` и `1-10-2026`. В текстовом списке `days` текущий день может называться «Сегодня», поэтому дата восстанавливается только из `per` и `DATE` записи.

Файл `app/src/test/resources/schedule-anonymized.json` сохраняет наблюдённую форму и диапазоны, но предметы, преподаватели, аудитории, ID и название группы заменены тестовыми значениями. Пустой день и второй слот в одной паре добавлены как тестовые случаи. Это **обезличенный тестовый пример**, не актуальное расписание.
